# Dead Frontier: Последний бастион

RTS про оборону базы от зомби.

## Как установить

1. Откройте раздел Releases справа и скачайте DeadFrontierLauncher.exe из последнего релиза.
2. Положите лаунчер в пустую папку, например C:\Games\DeadFrontier, и запустите.
3. Нажмите УСТАНОВИТЬ: лаунчер скачает игру (около 1,8 ГБ) в папку Game рядом с собой.
4. Дальше лаунчер сам проверяет обновления при каждом запуске.

Системные требования: Windows 10/11 64-bit, видеокарта с DirectX 12 (рекомендуется RTX).
